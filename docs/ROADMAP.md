# Roadmap

## v0.1 — implemented foundation
CLI, SQLite project registry, single active timer, worklogs, Markdown export, external CLI manifests, execution records, read-only API/dashboard, zsh wrappers, core tests.

## v0.2 — reliable personal workflow
Versioned migrations, JSON/CSV time exports, session correction audit trail, activity tags, artifact links, automatic backups, restore verification, structured command capability metadata, shell completions.

## v0.3 — consulting workspace
Client segregation, project-specific documentation templates, Git references, issue links, weekly reports, approval-ready timesheet exports, invoice preparation, data retention policies.

## v0.4 — developer operations
Native CLC release gates, DBScaffold integration, Onboarded provisioning, Terminal Workflow Kit workflows, tool-specific smoke tests, CI matrix, task runner, execution approval policies.

## v0.5 — distributed and secure
PostgreSQL, auth/RBAC, background workers, secret references, audit trail, multi-machine sync, external integrations after provider authorization.

## v1.0 — extensible platform
Stable plugin SDK, event bus, MCP interface, agent-safe read tools, integration tests, docs site, release automation, backup and disaster recovery exercises.
